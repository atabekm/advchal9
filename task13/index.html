          Three pause points, four ways to resume from each.
          

            Continuing without re-explaining is a claim about what the next turn needs,
            so it is measured by holding the pause point fixed and varying what gets
            sent. Every arm is graded against the same machine: what an arm was told
            has no bearing on what the guard will accept. The fixtures are logs, not
            states, because a state is a fold over a log and writing the fold by hand
            would be writing a second source of truth.
          

        

        

          
          
        

      


      
what each arm is paying for — counted here, with no key

      

        Work is the substance: artifacts, step titles, criteria, and what the person
        settled. Both arms carry every token of it and neither can drop any. What is
        left is what each pays on top. The plan predicted the state would be a
        fraction of the transcript. It is not.
      

      


      
and what happens when the model gets it wrong

      

        The state is a function of the machine, so anything that happens without
        moving the machine costs it nothing. A transcript has no such property:
        every refused attempt stays in it forever. The state line is flat by
        construction — that, and not compression, is what the state buys.
