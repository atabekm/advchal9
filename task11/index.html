The agent that knows where it put things

Three memory layers with three lifetimes — this dialogue, this task, this person — and seven rules that decide which one each thing goes into, in public.

Say something with a fact in it — your name, a deadline, a constraint — and watch the memory tab. Every candidate the model proposes is checked against the words that were actually said, then routed by a numbered rule into one of three stores that are deleted at three different times.

Open a task first if you want the middle layer to have a name. Then close the conversation and start another one: the person survives, the dialogue does not.

the three layers

Each one is a separate object with a separate lifetime, written to a separate key. Move anything by hand and the log records that a person did it.

stored separately, and here is the proof

Three namespaces in localStorage. Delete one and watch what the agent stops being able to answer — the other two are untouched, because they were never in the same record.

what survives what

Three lifetimes, which is the only thing that makes these three stores rather than one store with three labels.

what was retracted

A retraction is a write. Nothing is deleted silently, so something that was dropped on purpose can be told apart from something that was lost.

the rules

In order. First match wins, and the number travels with the write.

every decision, newest first

the task at hand

Working memory is bound to this. Close it and everything in it is archived — except what you choose to promote, which is the only moment the boundary between two layers is a decision instead of a rule.

what might outlive it

Decisions made inside the task. Promote the ones that are still true next month; the rest are archived with it and stay readable.

what would go up the wire now

Assembled without sending: the persona, then the person, then the task, then what was actually said — each layer its own system message.

the last turn cost two requests

The reply, and then the extraction that decided what to remember about it. Both are billed. The second one is what an explicit memory costs.

the ablation

One memory, built once from a seven-turn conversation. Then the same five questions asked four times, in a new conversation each time, with different layers unplugged. The answers cannot differ because of what was remembered — only because of what was sent.

It is live, it costs money, and it leaves your own layers untouched.
